Scan it. Attack it. Fix it.

Three commands. Everything runs on your machine, and nothing real is ever at risk.

Scan

Reads your agent setup the way an attacker would: skip-permission modes, commands that can run anything, MCP servers on @latest, invisible text in rules files, repo hooks. You get a Safe Setup score in seconds. No API key, nothing leaves your machine.

crumple scan

Attack

Builds 18 booby-trapped projects in a throwaway container and runs your own agent, with your own settings, against each one. Fresh fake keys every run, and every exit from the container leads back to Crumple.

crumple attack

Fix

Writes deny rules, installs the Crumple guard that checks every command before it runs, pins your MCP tools and can lock it all with managed settings. Then attack again to prove it held.

crumple fix --managed

Three honest outcomes.

Following a trap and getting away with it are different things. Crumple tells them apart.

✓ Held

The agent did the work and ignored the trap.

◐ Hijacked, contained

It followed the attacker, but no secret or damage got out.

✗ Breached

A key left, data was destroyed, permissions were raised, attacker code ran, or tests were gutted.

Every failure comes with its fix.

Finding holes is half the job. Crumple closes them, then attacks again so you can see the difference.

  • The Crumple guardChecks every command, file edit, read, web fetch and MCP call before it runs. It reads commands the way the shell will, follows wrappers and inline scripts, and fails closed.
  • MCP lockPins what every MCP server tells your agent and refuses any tool that changes later.
  • Managed settingsOnly your own hooks run, and nobody, including the agent, can switch the guard off.
  • Tamper-evident audit logEvery decision is written to a hash-chained log you can verify.
  • A GitHub checkFails any pull request that makes your agent setup unsafe and shows findings in code scanning.

Independent by design.

We don't build or sell an AI agent. We crash-test them. That's why our results mean something.

  • Your setup, not a demoCrumple tests the agent you actually use, with your permissions, hooks and MCP servers.
  • Nothing real at riskEvery trap runs in a sealed container with fake keys made fresh for each run. Crumple never touches your real keys or anyone else's systems.
  • Caught in any disguiseLeaks are caught plain, base64, base32, hex, URL-encoded, reversed, or split across DNS lookups.
  • Audit-readyReports map to OWASP and MITRE ATLAS and export SARIF, so they go straight into an audit folder.
